# Fußballrechner

Ligensystem ohne Relegation. Start: `index.html` öffnen.

Bundesliga, 2., 3. und 4. Bundesliga haben je 20 Vereine. Darunter liegen die 5. Liga Nordost und die 5. Liga Südwest mit je 18 Vereinen, und acht neue Regionalligen mit je 18. Auf- und Abstieg folgen nur der Tabelle. Die Regionalliga gibt einen festen Absteiger ab plus so viele, wie aus ihrem Gebiet von der 5. Liga kommen. Damit 18 Vereine bleiben, steigen je Regionalliga zwei Vereine aus dem Unterbau auf.

Die Startsaison füllt die Ligen nach der realen Ebene 2026/27 und dem Ansehen. Ab der 5. Liga zählt das Bundesland. RB Leipzig wird nicht gezeigt. Zweite Mannschaften bleiben draußen, außer SSV Jeddeloh II. Der Verein heißt SpVgg Fürth. SV Viktoria Bad Alexandersbad hat keine Liga.
