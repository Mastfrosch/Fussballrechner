# Fußballrechner

Offline-Liga- und Pokalrechner im Browser. Start: `index.html` öffnen, kein Server nötig.

Aktuelle Ligen: Bundesliga, 2. Bundesliga und 3. Liga mit je 20 Vereinen, die 4. Liga in Südwest und Nordost mit je 20, vier Regionalligen mit je 20 und elf Oberligen mit je 16. Platz 1 und 2 jeder 4.-Liga-Staffel steigen direkt auf. Es gibt keine Begrenzung je Richtung. Absteigen tun immer die Letzten der Tabelle. Die 3. Liga gibt die letzten vier ab, eine 4. Liga einer bis vier. In jeder Liga von der 3. Liga bis zur Oberliga steigt mindestens einer ab. Ergibt die Formel null, steigt der Letzte trotzdem ab, und aus der Liga darunter, in die er geht, steigt der Nächste hinter den regulären Aufsteigern zusätzlich auf. Eine Regionalliga kann bis zu sechs abgeben. Aus jeder Regionalliga steigt im Normalfall nur der Meister auf. Die Absteigerzahl gleicht die Zugänge aus, damit jede Liga ihre Sollgröße behält. Unter jeder Oberliga liegt eine Amateurliga mit demselben Gebiet; Meister und Vizemeister steigen auf. Dazu DFB-Pokal, 16 Landespokale und ab der zweiten Saison der Supercup. Ein Landespokal hat höchstens 128 Vereine.
