# Fußballrechner

Offline-Liga- und Pokalrechner im Browser. Start: `index.html` öffnen, kein Server nötig.

Aktuelle Ligen: Bundesliga, 2. Bundesliga, 3. Liga, 4. Liga, 5. Liga Nordost, 5. Liga Südwest, vier Regionalligen und je Bundesland eine Amateurliga. Dazu DFB-Pokal, 16 Landespokale und der Supercup.

Die Bedienung steht in [LIESMICH.txt](LIESMICH.txt).
