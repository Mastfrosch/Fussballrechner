# Fußballrechner

Offline-Liga- und Pokalrechner im Browser. Start: `index.html` öffnen, kein Server nötig.

Aktuelle Ligen: Bundesliga, 2. Bundesliga und 3. Liga mit je 20 Vereinen, die 4. Liga in Südwest (Regionalliga West und Süd) und Nordost (Regionalliga Nord und Nordost) mit je 20, vier Regionalligen mit je 18 und elf Oberligen mit je 16. Jede 4.-Liga-Staffel gibt fest zwei ab. Fehlende Plätze füllen die Meister und, wenn nötig, die Vizemeister der beiden Regionalligen darunter. Unter jeder Oberliga liegt eine Amateurliga mit demselben Gebiet. Dazu DFB-Pokal, 16 Landespokale und ab der zweiten Saison der Supercup. Ein Landespokal hat höchstens 128 Vereine.

Die Bedienung steht in [LIESMICH.txt](LIESMICH.txt).
