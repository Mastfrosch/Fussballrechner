# Fußballrechner

Die Vereine der Saison 2026/27, geordnet nach den realen Ligen. Start: `index.html` öffnen.

Angezeigt werden Name, Wappen, Bundesland, Stadion und, soweit vorhanden, die Koordinaten. Ein Klick öffnet die Vereinsinfo mit Meisterschaften, Pokalsiegen und der Ligahistorie. RB Leipzig wird nicht gezeigt. Zweite Mannschaften bleiben draußen, außer SSV Jeddeloh II. Der Verein heißt SpVgg Fürth.

Es gibt keine Simulation, keine Tabellenwertung und kein Ansehen.
