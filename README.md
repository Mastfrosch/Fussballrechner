# Fußballrechner

Ligensystem ohne Relegation. Start: `index.html` öffnen.

Bundesliga, 2., 3. und 4. Bundesliga haben je 20 Vereine. Darunter liegen die 5. Liga Nordost und die 5. Liga Südwest mit je 18 Vereinen, und acht neue Regionalligen mit je 18. Auf- und Abstieg folgen nur der Tabelle. Die Regionalliga gibt so viele ab, wie aus ihrem Gebiet von der 5. Liga kommen, damit 18 Vereine bleiben. Aus dem Unterbau steigt je Regionalliga der Meister mit den meisten Punkten pro Spiel auf.

Die Startsaison füllt die Ligen nach der realen Ebene 2026/27 und dem Ansehen. Ab der 5. Liga zählt das Bundesland. RB Leipzig wird nicht gezeigt. Zweite Mannschaften bleiben draußen, außer SSV Jeddeloh II. Der Verein heißt SpVgg Fürth. SV Viktoria Bad Alexandersbad hat keine Liga.
