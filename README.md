# Fußballrechner

Offline-Liga- und Pokalrechner im Browser. Start: `index.html` öffnen, kein Server nötig.

Aktuelle Ligen: Bundesliga, 2. Bundesliga, 3. Liga und 4. Liga mit je 20 Vereinen, vier Regionalligen mit je 18 und elf Oberligen mit je 16. Unter jeder Oberliga liegt eine Amateurliga mit demselben Gebiet. Dazu DFB-Pokal, 16 Landespokale und ab der zweiten Saison der Supercup. Ein Landespokal hat höchstens 128 Vereine.

Die Bedienung steht in [LIESMICH.txt](LIESMICH.txt).
